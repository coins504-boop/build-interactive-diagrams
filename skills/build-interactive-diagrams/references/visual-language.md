# 视觉表达与实时讲解约定

这是一套可复用的呈现层，不是第二套运行器。使用架构图的分区、留白、轻量图标与真实路径讲解，保留原生 draw.io 模型和执行逻辑。

## 一眼读懂的主图

- 主图显示真实 L1 区域及 L2 子节点。区域编号表示图中区域顺序，不表示业务执行步数
- 区域颜色由真实顶层容器分配，子节点继承；输入/终点用绿色、条件/等待用琥珀色、只读资料用紫色辅助识别。文字与图形形状共同表达含义
- 标签使用一个标题和一行简短元信息。图标只编码已有 role，不从标题猜测业务能力。用户标签必须 HTML 转义
- 容器标题、子节点、边标签留足空间。不要把长施工细节放进主图，也不要为了主图好看改动真实 parent、边端点、条件或动作
- 每个真实容器从相同原生几何快照分别试算横向和纵向层级布局，以有限尺寸、同级不重叠、子节点不越界为硬条件，再按容器长宽比与留白代价选择。它是启发式的矩形拟合，不是边交叉全局最优算法。区域内部整理后，再按实际视口比例及真实几何尺寸紧凑排列大小不等的顶层区域。使用真实跨区关系确定主流程顺序；有唯一产生区域的结果卡跟随该区域，其他独立输入、结果和只读资料使用横带。没有足够分区的图保留原生布局
- 连线始终是连接真实端点的原生边。跨区重新构图只改变 mxGeometry 与路由样式；拖动节点后仍由 mxGraph 路由，不能画脱离端点的装饰箭头
- 控制边与依赖边层次分明。依赖边更轻且有虚线，失败/等待/拒绝保留文字标签；不依靠颜色作为唯一解释

## 讲解来自真实状态

- 当前节点使用稳定明亮的 2.5 px 青色边与 1.1 px 近白亮芯；最后实际经过的控制边使用 2.25 px 连续青色细线、1 px 近白亮芯和至少 6 px 的原生方向箭头。光晕 sigma 为 1.05 CSS px、滤镜边缘最多 3.4 CSS px，并按当前变换修正，避免缩放后变粗。已经过路径使用较弱且不发光的绿色轨迹
- 不使用点状粒子、粗虚线、宽泛光晕或脉冲高亮。只照亮实际当前节点与最后真实边，没有假流量。暂停、等待、终点、取消和减少动态效果设置下，当前节点及路径都保持清晰
- 顶部短讲解展示实际 trace 的步数、当前节点、真实区域、运行状态和 reason；详细真实边与完整轨迹在检查栏查看。不把已发生步数伪装成总进度百分比
- 不新增模拟计时器、业务动画脚本、自动批准、循环假流量或运行完成后的自动镜头运动
- L3 角落视图从原模型投影，L4 点击展开。查看详情不暂停主运行；详情应继续跟随实际状态

## 画布优先的面板控制

- 标题栏、画布工具栏、当前步骤说明、右侧检查栏、角落局部图各自独立收起；恢复开关始终可达
- 专注画布一次收起这些面板，再次点击恢复此前的组合。工具栏隐藏时，原有“全图”按钮移到仍可见的开关栏或运行条
- 右侧检查栏隐藏时，将原来的场景选择、正常/失败/等待按钮、继续/暂停、单步、后退和批准/拒绝控件移到画布底部；恢复时放回原位。禁止克隆控件、重复 ID、第二条模拟或第二套计时器
- 切换面板不改运行状态、历史、等待决定、主图缩放或平移；局部图恢复时放弃旧的手动深入位置并跟随当前实际步骤
- 小视口允许底部控制换行，并为等待决定保留位置。自动测量运行条高度来缩减画布可用区域，不让审批控件遮住主图

## 验证要求

对每个新项目实际打开生成页面，检查最长标签、最大区域、分支与跨区边、主图和详情的占位。宽屏与较小桌面视口各检查一次。测试五类面板分别隐藏、专注模式恢复、侧栏隐藏后的原控件、运行中恢复局部图、暂停/单步/后退、等待批准与拒绝、取消、反复开始，以及拖动/平移/缩放后结束不改变视角。

自动测试证明声明式行为与元数据保留，不能证明所有图都已经视觉验收。复杂图允许用户通过原生节点拖动微调，再导出布局；不要声称任意规模都无需人工调整。
