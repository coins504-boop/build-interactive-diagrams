# 一个技能，按需深入

整份 build-interactive-diagrams 目录即可独立使用；保留 scripts、assets、references、examples、tests 和 licenses。无需拆成多个技能，也无需联网安装依赖。需要 Python 3.10+、Node.js 18+；输出放在技能目录外。以 [SKILL.md](../SKILL.md) 的工作路径为准。

## 三种深度

- 概览：解释要求覆盖的职责、输入输出和相互关系；不把读过文件或列出模块说成完整行为验证
- 重点流程：把指定旅程的决定、分支、状态变化和重要失败建成可播放解释；其余范围明确标为概述或未知
- 深入复核：在明确范围内补充源代码优先复查、相邻反例和时间/所有权边界；只有要求或确有必要时扩展，不默认审计全仓库

深度不改变真实性要求，也不能擅自缩小用户要求。源码图都保留来源身份、证据、覆盖限制、适用的准入/语义检查和实际构建收据。源码哈希、模拟通过、收据或轻量扫描都不能证明完整源码行为。

L1 是职责模块，L2 是主要步骤，通常在主图。真实复合操作的 L3 在局部图，更深处按需点开；原子步骤不强迫拆层。显示深度不改变执行顺序。

## 可直接复制的短提示词

需求设计：
“用 build-interactive-diagrams 把[需求]画成一张可交互单图。先讲清职责和端到端流程，标出假设；为适用分支做本地演示，交付工作区和施工包。”

源码重点流程：
“只读[授权目录/版本]，用中文解释[流程]和周边职责。重点流程可连续播放；保留源码证据、失败与未知边界，不运行上游项目，明确实际覆盖范围。”

源码概览：
“先给[项目]做职责概览，并演示[一个流程]。未深入的地方明确标注，不把概览说成全仓库验证。”

按需复核：
“对已有图的[具体范围]深入复核源码、默认行为、所有权/异步边界和反例；只修证据确认的问题，保留旧版及验证限制。”

## 使用边界

在支持 SKILL.md 并允许本地命令的宿主加载整个目录；具体发现/安装路径按该宿主当前文档配置。本包不自动安装、发布或修改宿主设置，也不声称已在 Codex/Hermes 中实际调用。

serve 仅监听本机；浏览器需与服务器共享 localhost，不支持直接 file:// 打开。模拟在内存中，刷新重置；导出保存原生布局/规格，不保存运行状态。它不执行上游项目或真实外部服务。离线 draw.io viewer、许可证和通知必须保留。

正常解压/克隆权限即可；不要把 assets 目录改为 0555，构建会复制其权限。复杂图仍需实际浏览器检查，不能承诺任何规模都自动清晰或流畅。包维护的测试和性能边界按需看 [VALIDATION.md](VALIDATION.md)，日常画图不必跑完整维护测试。
