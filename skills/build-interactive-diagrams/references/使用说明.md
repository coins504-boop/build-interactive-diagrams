# 单个可复用技能：使用说明

整份 build-interactive-diagrams 目录就是一个技能；SKILL.md、scripts、assets、examples、references、tests、licenses 必须一起保留，不需要多技能拼装。

## 能做什么

根据项目实际结构编写一个 JSON 规格，生成原生 draw.io 单画布、C 风格卡片、多层嵌套、逐步运行、正常/失败/等待分支、节点说明、原生图导出和施工交付。点击容器可查看内部，运行中的局部窗口继续跟随真实执行；详情查看不会主动暂停主流程。

标题、工具栏、步骤说明、侧栏和局部图可以分别收起。“专注画布”再次点击会恢复此前组合。侧栏收起后，原有场景、运行、暂停、单步、后退和批准/拒绝按钮移动到底部，仍控制同一次运行；工具栏收起时仍可使用“全图”。青色细实线与近白亮芯表示当前步骤，配合限制在屏幕像素范围的轻微光晕；绿色表示已走过路径。没有点状粒子或假流量。每个容器实际试算横向和纵向原生布局，再按几何评分选择。恢复局部图会显示此刻的实际步骤。

这不是通用业务代码自动实现器。它提供可扩展的项目规格格式与确定性模拟引擎；真实服务、账号、数据库、文件变更必须另行实现和授权。不会直接运行节点说明中的自然语言，示例业务政策也不是其他项目的默认规则。

## 开始

1. 在你可写的工作目录准备 project-spec.json。读取项目证据，按 references/contract.md 建模；两份 examples 仅供语法参考
2. 用 Python 3.10+ 运行 scripts/diagram.py validate 和 build；用 Node.js 18+ 执行 test
3. 输出目录须在技能目录外且为空。所有运行文件都包含在输出中，不访问 CDN，不需 npm/pip 安装
4. 用 serve 命令在本机打开；浏览器与服务器必须能访问同一个 localhost。file:// 打开不是支持路径
5. 检查视图、节点拖动、条件路径、等待决定和多轮回放，再交付 construction.zip

示例（先进入技能目录）：

```sh
python3 scripts/diagram.py doctor
python3 scripts/diagram.py test examples/greenhouse.json
python3 scripts/diagram.py build examples/greenhouse.json --out /你的可写工作目录/greenhouse-output
python3 scripts/diagram.py serve /你的可写工作目录/greenhouse-output --port 8000
```

Windows 可按实际环境用 python 命令。Node 测试脚本默认找 python3；需要时设置 PYTHON 为实际 Python 可执行文件。doctor只报告运行时可见情况，不校验Node最低版本；首次使用可另运行node --version确认18或以上。脚本不修改宿主配置、不安装依赖、不发布网站。保留普通克隆/解压权限：生成器会复制 assets 的目录模式，将源目录 chmod 555 会使输出也不可写。

## Codex / Hermes

技能入口采用标准 SKILL.md 前置元数据，工具只是普通 Python/Node 命令，不依赖某个宿主专用工具名。宿主安装发现规则可能随版本变化；本交付没有启动 Codex 或 Hermes，也没有在用户电脑安装。

一种共享布局是 ~/.agents/skills/build-interactive-diagrams/。Codex 支持该技能目录；Hermes 可按它的当前配置将此目录加入 skills.external_dirs，也可使用其自己的 skills 目录。这里仅说明配置选择，不自动修改任何设置。Hermes Docker 可能只读挂载技能，故输出目录不可放在技能内部。

## 验证边界

- Python/Node 版本与已验证用例以 references/VALIDATION.md 为准，不代表用户设备已有这些运行时
- 两个自带领域、重命名规格和合成布局夹具验证了部分可复用性，不能保证任意复杂项目无需调整
- 节点越多、条件越复杂，越需要补充独立输入与视觉验收。默认每次运行500次迁移，硬上限1000；后退不会退还预算，重开才重置
- 每次迁移保存回退快照，内存随轨迹长度近似平方增长；预算防止无限循环，不构成大规模性能承诺
- 本页状态仅在内存，刷新即重置。导出原生图保存布局和规格，不保存运行中的状态
- 显示真实条件边不等于图已经实现生产系统；施工包也不自动补齐项目缺失的生产决策
- 第三方 draw.io viewer 原字节保留；配套许可证与特殊图形许可说明必须随输出保留，未声称对所有嵌入图标做了穷尽法律审计
